The grounding problem (AI halucinations):

LLM are restricted to their training data:

1) Lack domain-specific knowledge.
2) Lack real-time data.
3) Cannot verify training data accuracy
	(a) Assume prompt truth
	(b) Cannot request context information

In RAG, we embed external documents into a vector database, retrieve the most relevant pieces using vector search, and then use that information to help the LLM generate a response.

Grounding is basically verifies the information generated by the LLM.

RAG is one of the method which performs grounding.

Grounded Agent: A search agent that helps in fact-check.
