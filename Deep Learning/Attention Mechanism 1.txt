We can add attention mechanism to encoder decoder model.

Using attention mechanism we can train the neural network to focus on specific words. 

It is done by adding more weights to the words which are to given more focus.

In a traditional RNN encoder decoder model, in the encoding it takes one word at a time and updates the hidden state and the final hidden state is passed on to the decoder for the decoding.  

In Attention Encoder Decoder model sends a lot more data to the decoder from the encoder. What it does is that it sends all the hidden state at all the time step so that the decoder has more context so that the decoder can translate better. 

In Attention Encoder Decoder model, at the decoding state it checks all the hidden states at all the time steps. Each hidden state represent a particular word. Based on that hidden state it gives scores to the hidden states and then finds the SoftMax score of the hidden states. Then, they multiply all those hidden states with their SoftMax scores thus downsizing those with low scores and amplifying with high scores.

Hd represents the Hidden state of the Decoder at each time step.

H represents the Hidden state of the Encoder at each time step.

Alpha represents the Attention Weights at each time step.

We use Hd to generate scores of the hidden state. These scores are generated by comparing Hd and H and by that we get the attention weights. By using the attention weights alpha we get the value of context vector. We then concatenate the context vector with the Hd to get which words are more relevant. Then this is passed through a FNN to get the final outcome.
