Module 1: Machine Learning with Python

Machine Learning Paradigms:

1) Supervised Machine Learning: The models trains on labeled data.

2) Unsupervised Machine Learning: Works without labeled data.

3) Semi-supervised Machine Learning: Semi-supervised Machine Learning trains on a relatively small subset of data that is already labeled and iteratively retrains itself by adding new labels that it generates with reasonably high confidence.

4) Reinforcement Learning: It learns from feedback

Machine Learning Model Lifecycle:

1) Problem Definition
2) Data Collection
3) Data Preparation
4) Model Development and Evaluation
5) Model Deployment

Data Collection and Data Preparation Process is also called as the ETL process.

ETL stands for Extract, Transform and Load.
