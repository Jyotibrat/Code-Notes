Feature Extraction: Feature extraction in NLP is the crucial process of converting raw, unstructured text into meaningful numerical formats (vectors/matrices) that machine learning models can understand and process, simplifying complexity by highlighting key information like word frequencies (Bag of Words, TF-IDF) or capturing semantic meaning (word embeddings like Word2Vec, GloVe, BERT), thereby improving model efficiency and accuracy.

The assigning of the numbers that describe a document in relation to the corpus that it contains. This is feature extraction.

The word with the highest numerical value is considered as the most important word.

Bag of words: It is a feature Extraction process where we count the frequency of each word and based on that the word which has the most frequency is considered as the most important word.

The class TfidfVectorizer does pre processing and also calculates the TF-IDF scores both, but the class TfidfTransformer only calculates the TF-IDF scores. For the later one we need to perform text pre processing manually or using some other library.
