Stemming: Stemming is the process which converts words to their base form by removing their prefixes and suffixes. 

Eg: Running ---> Run

Lemmatization: It is similar to Stemming but there is a difference. The difference is that in lemmatization we convert words to their base form using morphological analysis and their literal meaning.

Eg: Saw ---> See

Contractions: Contractions means the words which are written in short form which computers finds hard to understand to they need to be expanded.

Eg: I'll ---> I will

Using the emoji library of python we can remove emoji from sentences.

Eg: Nice to meet you 😁 ---> Nice to meet you :beaming_face_with_smiling_eyes:

We can spellings using the python library spellchecker and with the instance method SpellChecker.

To use this we need to install the library. 
The main library name is pyspellchecker.
To use the instance method we first need to create an object of SpellChecker then only we can use it.
